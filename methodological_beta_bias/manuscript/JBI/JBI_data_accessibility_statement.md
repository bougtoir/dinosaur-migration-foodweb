# Data Accessibility Statement (JBI)

All occurrence data derive from published public sources: the Maidment et
al. (2024) Dryad package (DOI 10.5061/dryad.6m905qg77, CC0) and the
Paleobiology Database (public API; download parameters and sha256
checksums recorded in `metadata/sources.csv`). All simulation and analysis
code, frozen random seeds (seed sets 20260920–20260925), and the
value-level registry (`results/manuscript_values.csv`, which maps every
manuscript number to its generating script and output file) are available
in the public reproducibility repository; an anonymized repository URL is
provided for double-anonymous review and will be replaced by the permanent
public repository/DOI on acceptance. The repository also contains the full
parameter and seed registry, complete sweep outputs, the taxonomic
reconciliation table, Morrison locality map, species-resolution and
presence-model diagnostics, extended Nemegt diagnostics, the complete
independent-evidence audit, and provenance/checksum records. The full
pipeline reproduces with the Makefile entry points documented in the
repository README. No journal Supporting Information is required.
