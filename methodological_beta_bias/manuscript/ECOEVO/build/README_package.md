# Ecology and Evolution submission package

- `ECOEVO_main_manuscript.docx`: main document for upload (title page block, abstract, text, statements, references, Tables 1–3 on separate pages, figure legends; continuous line numbers).
- `ECOEVO_main_manuscript_inline.docx`: identical text with figures and tables placed after their first citation (reading copy).
- `ECOEVO_title_page.docx`; `ECOEVO_cover_letter.docx` (Wiley transfer route); `ECOEVO_cover_letter_direct_submission.docx` (direct new submission if the transfer link stays broken; adds the transfer-ticket sentence).
- `tables/ECOEVO_tables.docx`: Tables 1–3 (editable).
- `figures/Figure1–6.tif` (300 dpi, upload as Figures), `.png` copies, and `ECOEVO_figures_editable.pptx`.
- `reviewer_files/`: source-data registry, manuscript value registry and independent-evidence audit (canonical copies in the public repository).
- `audits/`: pre-submission audit reports.
