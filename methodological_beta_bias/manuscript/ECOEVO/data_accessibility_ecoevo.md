All occurrence data used in this study derive from publicly available sources: the Morrison Formation dataset of Maidment (2024), archived in Dryad at https://doi.org/10.5061/dryad.6m905qg77 (CC0), and occurrence records from the Paleobiology Database (https://paleobiodb.org/).

The complete simulation and analysis code, fixed random seeds, provenance records, processed analysis inputs and value-level numerical registry are publicly available at https://github.com/bougtoir/dinosaur-migration-foodweb. The repository contains the source-data registry with download parameters and SHA-256 checksums (`metadata/sources.csv`), the manuscript value registry (`methodological_beta_bias/results/manuscript_values.csv`), the independent-evidence audit (`methodological_beta_bias/INDEPENDENT_EVIDENCE_AUDIT.md`), the parameter and seed registry (`methodological_beta_bias/results/parameter_seed_registry.csv`), complete simulation outputs, the taxonomic reconciliation table, Morrison locality and taxon-distribution materials, species-resolution and presence-model diagnostics, extended Nemegt diagnostics, and the scripts required to reproduce the analyses and figures. Reproduction entry points are documented in the repository README and Makefile (`make beta_bias`).

For reviewer convenience, copies of `metadata/sources.csv`, `methodological_beta_bias/results/manuscript_values.csv`, and `methodological_beta_bias/INDEPENDENT_EVIDENCE_AUDIT.md` are also supplied with the submission as supplementary reviewer files. The versions in the public repository are the canonical versions.
